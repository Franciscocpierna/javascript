Importância dos Atributos

  • src: Especifica o caminho para a imagem que você deseja exibir.
  • alt: Fornece uma descrição alternativa da imagem para acessibilidade. Isso é essencial para leitores de tela e em casos onde a imagem não pode ser carregada.
  • title: Oferece uma informação adicional quando o usuário passa o mouse sobre a imagem, geralmente usado para fornecer contexto adicional ou explicar a imagem.
